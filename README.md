# College Complaint & Issue Tracking System

A responsive frontend GUI prototype for a college complaint and issue tracking platform.

## Included
- Landing page
- Student login/register/forgot password
- Student dashboard
- Submit complaint form
- Complaint tracking with timeline
- Complaint history and search
- Admin dashboard
- Admin complaint management
- Reports and analytics
- Staff/department dashboard
- Notifications
- Profile and settings
- Responsive mobile navigation
- Sample complaint data
- Toast messages and interactive UI

## Run
No build tools are required for this GUI prototype.

1. Extract the ZIP.
2. Open `index.html` in a browser.

For the best experience, use a local server such as VS Code Live Server.

## Demo
On the login page, use the demo role buttons:
- Student
- Staff
- Admin

This is a frontend GUI prototype. MongoDB, Node.js/Express REST APIs, real authentication, file storage, and production security can be connected later.
